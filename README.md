## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Abhishek-00007/GreatLearning_DailyCode.git
```

### Navigate to the Repository

```bash
cd GreatLearning_DailyCode
```

### Run a .NET Project

```bash
dotnet restore
dotnet build
dotnet run
```

### Run Tests

```bash
dotnet test
```

### Run Angular Projects

```bash
npm install
ng serve
```
